# Todo SaaS Azure

A production-style Todo application built to learn Azure cloud architecture.

## Goals

- Build a full-stack application
- Deploy using Azure services
- Learn Azure administration concepts
- Practice AZ-104 certification objectives
- Implement cloud best practices incrementally

## Architecture

Current stage:

React → ASP.NET Core API → In-memory storage

Future evolution:

React
↓
Azure hosting
↓
ASP.NET Core API
↓
Azure SQL
↓
Azure Storage
↓
Managed Identity
↓
Monitoring and Security
